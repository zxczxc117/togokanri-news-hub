# サイト設定リファレンス（config/sites/<id>.json）

1ファイル＝1サイトです。**このファイルだけでサイト個別の調整が完結する**ように
作ってあります。追加するときは `_template_html.json` を複製して名前を変えてください
（先頭が `_` のファイルは読み込まれないので、ひな型は消さずに残せます）。

---

## 1. 全項目

```json
{
  "id": "4gamer",
  "name": "4Gamer.net",
  "category": "GAME",
  "enabled": true,
  "allowFullText": true,
  "maxItems": 80,
  "listing": {
    "type": "rss",
    "urls": ["https://www.4gamer.net/rss/index.xml"],
    "linkSelector": "",
    "linkAttr": "href",
    "urlIncludePatterns": [],
    "urlExcludePatterns": []
  },
  "article": {
    "titleSelectors": ["h1"],
    "bodySelectors": ["#maincontents", ".text"],
    "dropSelectors": [".ad", ".related"],
    "imageSelectors": ["meta[property='og:image']"],
    "dateSelectors": ["meta[property='article:published_time']", "time[datetime]"],
    "stopAtTexts": ["関連記事"],
    "minParagraphChars": 25
  },
  "notes": "調整の経緯をここに書いておくと次回の判断が早い"
}
```

| 項目 | 意味 | 既定 | 迷ったとき |
|---|---|---|---|
| `id` | サイトID。アプリ側の取得元IDは `hub_<id>` になる | 必須 | 英数字と `_` のみ。**後から変えない** |
| `name` | 表示名 | id | 記事カードの媒体名に出る |
| `category` | `GENERAL` `TECH` `GAME` `STOCK` `MATOME` の5値 | GENERAL | アプリのタブ振り分けに直結 |
| `enabled` | falseで一時停止（設定は残す） | true | 落ちているサイトを止めるときに使う |
| `allowFullText` | 本文を配信JSONに含めてよいか | true | 再配信を許していない媒体は **false** |
| `maxItems` | 配信JSONに載せる件数（1〜300） | 80 | 要望の「50〜100件」は60〜100が目安 |
| `listing.type` | `rss`（RSS/Atom/RDF）または `html`（一覧ページ） | rss | RSSがあるなら常にrssが楽 |
| `listing.urls` | 一覧のURL（複数可） | 必須 | カテゴリ別RSSを並べれば件数を稼げる |
| `listing.linkSelector` | type=htmlのとき、記事リンクのCSSセレクタ | — | type=htmlでは必須 |
| `listing.linkAttr` | リンクURLを持つ属性 | href | `data-href` のサイトもある |
| `listing.urlIncludePatterns` | このどれかを含むURLだけ拾う | 空=制限なし | `"/news/"` など |
| `listing.urlExcludePatterns` | このどれかを含むURLは捨てる | 空 | `"/tag/"` `"/author/"` |
| `article.titleSelectors` | 見出し。最初に当たったものを使う | `["h1"]` | 末尾に og:title と title が自動で足される |
| `article.bodySelectors` | **本文の入れ物**。最初に当たったものを使う | 空 | 空なら汎用推定（文字が濃い塊）に任せる |
| `article.dropSelectors` | 先に丸ごと捨てる要素 | 標準の広告・関連系 | 広告が本文に混ざるときはここを足す |
| `article.imageSelectors` | 画像URL。og:image が最も安定 | og:image / twitter:image | 記事内の1枚目を使いたいなら `article img` |
| `article.dateSelectors` | 公開日時 | article:published_time / time | 取れないときはRSSの日付、無ければ取得時刻 |
| `article.stopAtTexts` | この文字が出た段落以降を捨てる | 関連記事など | 記事末尾に固定の見出しがある媒体で有効 |
| `article.minParagraphChars` | この文字数未満の段落（p）を捨てる | 0 | 日本語記事なら20〜30が目安 |
| `notes` | 覚書（処理には使わない） | — | 「なぜこのセレクタか」を残す |

## 2. セレクタの書き方（CSSセレクタの範囲）

BeautifulSoup（soupsieve）のCSSセレクタが使えます。よく使う形だけ覚えれば足ります。

| 書き方 | 意味 |
|---|---|
| `#maincontents` | id が maincontents の要素 |
| `.article-body` | class に article-body を持つ要素 |
| `div.entry-body` | div かつ class が entry-body |
| `article .body` | article の内側の .body |
| `meta[property='og:image']` | property属性が og:image の meta |
| `time[datetime]` | datetime属性を持つ time |
| `div[class*='article']` | class に article を含む（部分一致） |

**優先順に複数書けます。** 上から試して最初に当たったものを使うので、
`["#article-body", ".entry-body", "article"]` のように
「狙い撃ち → ゆるい指定 → 最後の砦」の順に並べるのが安全です。

## 3. 調整の進め方（手元で確認しながら）

```
# 1サイトだけ・5件だけ・書き出さずに試す
python -m collector.main --site 4gamer --limit 5 --dry-run

# セレクタを直したら、机上検証で壊れていないかを確認
python -m collector.selftest
```

Windowsなら `tools\local_run.bat` にサイトIDを渡しても同じことができます。

## 4. よくある症状と直し方

| 症状 | 原因 | 直す場所 |
|---|---|---|
| 本文が0件（概要だけになる） | bodySelectorsが当たっていない | `bodySelectors` を記事HTMLの実際のid/classに直す |
| 広告・関連記事が本文に混ざる | 除去が足りない | `dropSelectors` に足す／`stopAtTexts` を設定 |
| メニューの語句が段落として拾われる | 短文が通っている | `minParagraphChars` を20〜30に上げる |
| 記事末尾に別記事の見出しが続く | 打ち切り位置が無い | `stopAtTexts` に固定の見出し語を入れる |
| 画像が出ない | og:imageが無い／httpsでない | `imageSelectors` に `article img` を追加（httpsのみ採用） |
| 日付が全部「今」になる | 日付要素が読めていない | `dateSelectors` を追加。JSON-LDの datePublished も自動で見る |
| 件数が少ない | 一覧が少ない | `listing.urls` にカテゴリ別RSSを追加 |
| 関係ない記事が混ざる | 一覧に一覧以外のリンク | `urlIncludePatterns` / `urlExcludePatterns` で絞る |
