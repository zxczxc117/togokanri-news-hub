# 稼働手順書（GitHubで動かすまで）

所要時間の目安：**10〜15分**。GitHubアカウントがあれば他の準備は要りません。
費用はかかりません（publicリポジトリのActionsは無料枠）。

---

## 1. リポジトリを作る

1. GitHub で **New repository**
2. 名前：`togokanri-news-hub`（変えてもよい。あとでURLに出る）
3. 公開設定：**Public**
   - privateでも動きますが、アプリからJSONを読むために認証が必要になり、
     端末にトークンを持たせることになります。個人ニュースの取り込みでは
     public＋「公開してよい内容だけ置く」方が単純で安全です。
4. README等のチェックは付けずに作成

## 2. このフォルダの中身を上げる

Web画面だけで完結させる場合：

1. リポジトリの **Add file → Upload files**
2. `togokanri-news-hub` フォルダの中身（`collector/` `config/` `docs/` `samples/`
   `tools/` `public/` `state/` `.github/` `requirements.txt` `README.md` `.gitignore`）
   を **フォルダ構造ごと** ドラッグ＆ドロップ
3. Commit

`git` を使う場合：

```
cd togokanri-news-hub
git init
git add .
git commit -m "init: news hub"
git branch -M main
git remote add origin https://github.com/自分のID/togokanri-news-hub.git
git push -u origin main
```

> `.github/workflows/collect.yml` が入っていないと1日3回の実行が始まりません。
> Uploadのときに `.github` フォルダが除外されていないか必ず確認してください
> （エクスプローラで隠しフォルダ扱いになる場合があります）。

## 3. Actions に書き込み権限を与える

収集結果（`public/` と `state/`）をリポジトリへコミットするため、
既定の読み取り専用では失敗します。

1. リポジトリの **Settings → Actions → General**
2. 一番下の **Workflow permissions**
3. **Read and write permissions** を選んで Save

## 4. Actions を有効化して手動実行する

1. **Actions** タブ →「I understand my workflows, go ahead and enable them」
2. 左の一覧から **collect-news** → 右上 **Run workflow**
   - `site` を空欄にすると全サイト。最初の1回は `--limit` を効かせたいので
     `limit` に `5` を入れて軽く試すのがおすすめです
3. 緑のチェックになったら **Code** タブで `public/index.json` と
   `public/sites/*.json` ができていることを確認

初回は記事の本文を取るため時間がかかります（全サイト・上限40件で5〜15分程度）。
2回目以降は「更新がある記事だけ」なので短くなります。

## 5. 配信URLを確認する

`public/index.json` を開き、右上の **Raw** を押してURLをコピーします。
形は次のとおりです。

```
https://raw.githubusercontent.com/自分のID/togokanri-news-hub/main/public/index.json
```

アプリに入れるのは **末尾の index.json を除いたフォルダのURL** です（どちらでも受け付けます）。

```
https://raw.githubusercontent.com/自分のID/togokanri-news-hub/main/public/
```

> GitHub Pages を使う場合は `.github/workflows/pages.yml` を有効にして
> Settings → Pages で Source を「GitHub Actions」にします。
> 配信URLは `https://自分のID.github.io/togokanri-news-hub/` になります。
> raw.githubusercontent.com で足りるなら Pages は不要です（pages.yml は削除可）。

## 6. アプリ側の設定

1. 情報（ニュース）→ 右端の **設定** タブ
2. **配信JSON（GitHub）** の区画
3. 「配信JSONから取り込む」を ON
4. 配信URLを貼って **URLを保存**
5. **配信JSONを今すぐ取得** を押す
   - 「サイト11件 / 新規○件 / 更新○件」と出れば成功
6. 以降は手動更新・定時取込のたびに自動で確認されます
   （更新の無いサイトは index.json を見るだけで通信を終えます）

## 7. 実行時刻を変えたいとき

`.github/workflows/collect.yml` の `cron` を直します。**UTC指定**なので
日本時間から9時間引いて書きます。

| 日本時間 | cron（UTC） |
|---|---|
| 06:50 | `50 21 * * *` |
| 12:20 | `20 3 * * *` |
| 19:50 | `50 10 * * *` |

GitHubの共有ランナーは混雑時に数分〜十数分遅れて起動します。
「その時刻ちょうど」ではなく「その頃に1回」という精度で運用してください。

## 8. うまくいかないとき

`docs/05_トラブルシュート.md` に症状別の対処をまとめています。
Actionsのログは **Actions → 該当の実行 → collect → 各ステップ** で読めます。
`run-log` というアーティファクトにも同じログが14日間保存されます。
