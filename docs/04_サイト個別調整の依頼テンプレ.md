# サイト個別調整をAIへ依頼するときのテンプレ

サイトのHTML構造が変わって本文が取れなくなったときは、
**次の3点セット**を渡せば直せます。Pythonのコードを渡す必要はありません。

---

## 渡すもの（この3つで足りる）

1. `config/sites/<id>.json`（対象サイトの設定1ファイル）
2. `docs/02_サイト設定リファレンス.md`（設定項目の意味）
3. **対象記事ページのHTML**（ブラウザで「ページのソースを表示」→全選択コピー、
   または `Ctrl+S` で保存したファイル）
   - 一覧の拾い方を直す場合は **一覧ページのHTML** も
   - HTMLが大きすぎる場合は、本文の前後200行程度の抜粋でも判断できます

## 依頼文のひな型（そのままコピーして使えます）

```
TogoKanri のニュース配信JSON（togokanri-news-hub）で、サイト「<サイト名>」の
本文が正しく取れなくなりました。config/sites/<id>.json のセレクタを直してください。

【症状】
- 例）本文が0件になり、概要だけがアプリに出る
- 例）記事末尾に「関連記事」の見出しが20件ぶん混ざる
- 例）画像が出ない

【現在の設定】
（config/sites/<id>.json の中身を貼る）

【記事ページのHTML】
（該当記事のHTMLを貼る。長い場合は本文部分の前後を抜粋）

【期待する結果】
- 本文が段落として取れる（広告・関連記事・SNSボタンは含めない）
- 画像は og:image を使う
- 公開日時が記事の日時になる

【制約】
- 直すのは config/sites/<id>.json だけにしてください（collector/ は変更不要）
- 変更後は python -m collector.selftest が PASS することを確認してください
- 変更点は「置換前／置換後」で示してください
```

## 受け取ったあとの確認手順

```
python -m collector.selftest                         # 設定の形が壊れていないか
python -m collector.main --site <id> --limit 5 --dry-run
```

ログに `新規5 更新0` のように出て、`本文` が取れていれば成功です。
`--dry-run` を外して1回流し、`public/sites/<id>.json` の `bodyBlocks` に
段落が入っていることを確認してからコミットしてください。

## 収集の仕組み自体を直してもらう場合

セレクタでは対応できない構造（記事本文がJavaScriptで組まれる、
ページ送りが必要、APIから取る方が確実、など）のときは、
`collector/listing.py` または `collector/extractor.py` を渡します。
そのときも **渡すのは対象の2ファイルと該当サイトの設定だけ** にしてください。
`main.py` `state.py` `publisher.py` は差分判定と出力形の担当なので、
「取得の仕方」の相談には不要です（渡すほど回答がぶれます）。
